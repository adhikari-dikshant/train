# Independent cultural collage cutouts

Generated with the built-in image-generation tool for this website. The eight transparent WebP files in `assets/` replace the rectangular Three.js image slices. The complete original JPEGs remain as the static fallback when WebGL is unavailable. These are generated editorial illustrations, not documentary photographs. WebP conversion preserves alpha; no new runtime dependency was added.

## Shared prompt

Use case: illustration-story. Asset type: transparent PNG cutout for an interactive Indian cultural travel collage. Reference style: the attached HASSTRA train-window collage, warm hand-painted vintage travel scrapbook, realistic photographic detail softened into gouache on aged paper, fine visible paper grain, earthy sandstone and terracotta with rich indigo, orange marigold and teal accents. Subject: [subject below] Composition: isolated single cutout filling canvas with 5% transparent padding, no clipping of extremities. Constraints: genuine transparent alpha background, NO colored background, NO frame, NO lettering, NO text, NO cast shadow outside silhouette, no watermark. All edges follow the actual subject contours; not a rectangular image. Keep the style warm, tactile and realistic, not vector art or cartoon.
